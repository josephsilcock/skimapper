F1 Resort list: home screen sketch

A static sketch at the 480 px demo viewport, in Flutter's default Material 3 look, which the app uses today. The content is the real curated list. The "couldn't refresh" message is a standard bottom SnackBar and isn't drawn.

1. Home screen with the list

The list takes the flexible space and scrolls under pull-to-refresh. The fixture map block stays pinned below it at today's 240 px until F5. Each row shows the name, with the countries on a smaller second line, and has no chevron and no ripple until F4.

To rule on: the map block is pinned below the list, rather than scrolling away under it.

2. First launch, nothing saved

All three states fill only the list area. The map block stays below, and the area remains pullable.

To rule on: "update the app" offers Retry as well as pull (the spec keeps both available), with the same layout as "couldn't load".

3. "Update the app" over a saved list

The saved list stays usable and pullable. The prompt clears when a later fetch is understood.

To rule on: which treatment. Recommended: A, a MaterialBanner at the top of the list area. It's persistent, doesn't cover rows and is standard Material. B floats over the bottom rows, which reads like a SnackBar that won't leave.
