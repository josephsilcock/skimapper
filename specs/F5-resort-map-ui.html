Tap affordance: a trailing chevron

Each card gets a trailing chevron and the standard ink ripple on tap. The credits line is no longer in the list screen's bottom bar, so the list stands alone.

Name bar, map, credits below the map

The name bar is a plain app bar on the teal-grey ground: a back arrow and the resort name in the primary colour, matching the list screen's title. The map fills the space between the name bar and the credits. The credits sit in the bottom bar, outside the map, where the list screen has them today. MapLibre's own logo and attribution button are off. The compass shows only when the map is rotated, and tapping it turns the map back to north.

novice: green easy: blue intermediate: red advanced, expert: black freeride, extreme: dashed dark no difficulty: grey aerial lift: dark core in a white casing, with station dots drag lift: dotted core in the same casing

Background: Protomaps' grayscale flavour with points of interest removed. Only town, village and peak names are kept, in grey. The terrain is hillshaded in neutral greys over the land cover and under the roads and labels.

Rule on: (a) lifts set apart from runs by a white casing, which no run has, with drag lifts dotted; (b) credits in a bar below the map rather than over the map's bottom edge; (c) town and peak names kept on the background.

Full-area states replace the map, the name bar stays

These follow the list's full-area state style. The name bar and back control stay, so the skier always knows which resort they opened and can leave. There are no credits while no map data is shown.

The other two states differ only in their contents. Loading is a centred progress indicator. "Update the app" uses the system-update icon, the heading "Update SkiMapper to see this map", the detail "This version can't read this resort's map.", and the same Retry button.
