# Specs (transient)

Pre-implementation specs for work **in flight**. A spec proposes a delta to the area docs
(`docs/definitions/`); at `/finish-feature` the as-built behaviour merges into the area docs,
noteworthy decisions move to `docs/DECISIONS.md`, and the spec file is **deleted** — git history is
the archive. An epic's parent spec survives until the epic's exit criteria are met.

So: anything in this directory is either being built now or approved-and-waiting.
